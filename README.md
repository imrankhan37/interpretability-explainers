# Interpretability Explainers

Small, self-contained interactive guides to mechanistic interpretability, by [Imran Khan](https://www.linkedin.com/in/imran-khan37).

**Live site: https://imrankhan37.github.io/interpretability-explainers/**

## Explainers

- **Patching & Steering as Causal Analysis** ([open](https://imrankhan37.github.io/interpretability-explainers/activation-patching.html)) — activation patching and steering framed as causal interventions, worked through an IOI-style example with feature-level patches.

## Notes

Each explainer is a single self-contained HTML file. There is no build step and no dependencies beyond CDN-loaded fonts and KaTeX. Open the file directly in a browser, or visit the live site above.
