Before we intervene

The model state, read through a feature dictionary

At a single token, the model's internal state is one long activation vector xᵢ. On its own it is hard to read: thousands of numbers with no obvious meaning.

A learned dictionary changes that. It is a matrix whose rows are interpretable feature directions: one row for a Mary-IO feature, one for a John-IO feature, one for a syntactic feature, and so on. Reading the activation through the dictionary gives a weight on each row: a coefficient saying how strongly that feature is active right now.

For this guide, assume the dictionary is already given. How it is learned (sparse autoencoders, the training objective, how the feature directions are found) is a separate topic we set aside here.

So the same state has two views: the raw vector, or a short list of named coefficients. The interactive below works in the second view, because a named coefficient is something you can actually intervene on and reason about.

The causal lens

Feature ledger

Whole-vector patching

Replace the whole activation at this layer/token with the target run’s activation. This is a causal intervention, but a coarse one: it imports name, syntax, and position information along with unrelated directions.

Feature-level patching

Keep the base vector, but set only selected feature coefficients to their target-run values: a precise counterfactual, restricted to the coordinates you choose.

Steering

Choose a direction and push. There may be no target sentence at all; the amount λ is a dose you set yourself.

Takeaway

Patching and steering are both causal tools because they intervene on the model’s internal computation and measure the downstream change. Patching chooses the intervention from a real counterfactual run; steering chooses a direction and a dose.

  • John-only patch: adds John evidence, but Mary evidence remains.
  • Mary + John patch: subtracts Mary evidence and adds John evidence, so the base run becomes target-like in just those selected coordinates.
  • Real models: the feature directions are not usually perfect 2D axes; this diagram is the clean mental model.
  • Core causal idea: observation says “this feature is present”; intervention asks “does changing this feature change the answer?”
